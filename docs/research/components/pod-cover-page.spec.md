# PodCoverPage Specification

## Overview

- **Target file:** `pod-cover/index.html` generated by `scripts/build-clone.mjs`
- **Screenshot:** `docs/design-references/eightsleep-ca-pod-cover-desktop-top.png`, `eightsleep-ca-pod-cover-mobile-top.png`
- **Interaction model:** scroll-driven reveals/media with click/drag card swipers and video controls

## DOM structure

Shared fixed shell followed by `Pod5Hero_container`, whole-bed system cards, Autopilot/add-on callouts, two-sleeper temperature content, feature card-swiper groups, sound/elevation/alarm sections, sleep-metric and health-check sections, user story/timeline content, closing CTA, footer, and hidden consent structures.

## States & behaviors

- `type_animated` headings start at opacity `0` / translate `30px` and reveal during scroll.
- CardSwiper groups preserve their original card order, images, hidden state, and client controls.
- Video placeholders retain their poster/media attributes and original play controls.

## Responsive behavior

- **Desktop 1440px:** centered title block and wide rounded media panel; system cards and feature panels use multi-column layouts.
- **Tablet 768px:** columns compress and card swipers retain horizontal interaction.
- **Mobile 390px:** title wraps to two lines, copy narrows, CTA centers, media becomes a rounded single-column card, and nav becomes compact.
- **Breakpoint:** original captured responsive CSS controls the exact switch points.
