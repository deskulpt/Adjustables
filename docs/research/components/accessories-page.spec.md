# AccessoriesPage Specification

## Overview

- **Target file:** `accessories/index.html` generated by `scripts/build-clone.mjs`
- **Screenshot:** `docs/design-references/eightsleep-ca-accessories-desktop-top.png`, `eightsleep-ca-accessories-mobile-top.png`
- **Interaction model:** responsive product grid with hover/click links and mobile filter control

## DOM structure

Shared promo/navigation shell, accessories content wrapper, heading/filter row, product cards, product-detail content blocks, footer, and hidden consent structures. Each product card contains image, optional `NEW` badge, title, compatibility badge, description, price, and black `Shop now` button.

## States & behaviors

- Product cards use the captured CSS hover states and link targets.
- Mobile filter control is visible in the 390px reference and absent from the desktop card heading row.
- Scroll-triggered animated content uses the shared `type_animated` behavior.

## Responsive behavior

- **Desktop 1440px:** heading at `x=64px`; three-column grid with wide white rounded cards and large square product media.
- **Tablet 768px:** grid reduces its column count while preserving card surfaces and CTA hierarchy.
- **Mobile 390px:** two-column grid, compact product imagery, wrapped badges, vertically stacked copy/price/button, filter icon beside heading.
- **Breakpoint:** original captured responsive CSS controls the exact switch points.
