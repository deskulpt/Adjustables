# HomePage Specification

## Overview

- **Target file:** `index.html` generated by `scripts/build-clone.mjs`
- **Screenshot:** `docs/design-references/eightsleep-ca-desktop-top.png`, `eightsleep-ca-mobile-top.png`
- **Interaction model:** scroll-driven reveals with click-driven feature/review tabs

## DOM structure

Rendered source DOM contains a fixed `header`, a main content wrapper with the hero and feature sections, repeated image/video cards, tablist/tabpanels for reviews, advisory profiles, closing CTA, footer, and hidden consent/chat infrastructure. The original class names are preserved in the generated route.

## States & behaviors

- `type_animated`: inline opacity/translate state changes on viewport entry; local fallback uses `IntersectionObserver` with `threshold: 0.12` and `rootMargin: 0px 0px -8% 0px`.
- Feature tabs: `Temperature`, `Elevation`, `Sound`; active panel changes with the original client tab state.
- Review tabs: `Hot sleepers`, `Couples`, `Fitness enthusiasts`, `Troubled sleepers`; only selected `tabpanel` is visible.
- Outcome metrics: `.BestSleepYouveNeverHad_stat_container__W5okL` and axis ticks start at `transform: translate(0px, 100%)`, `opacity: 0`; local behavior adds `clone-stat-visible` with a `900ms cubic-bezier(.16, 1, .3, 1)` lift, 28ms per-marker stagger, and a vertical sceptre scale draw.

## Responsive behavior

- **Desktop 1440px:** full-bleed hero, desktop nav, large two-column/row feature layouts.
- **Tablet 768px:** desktop content compresses; card rows reduce and media keeps aspect ratio.
- **Mobile 390px:** portrait hero crop, centered headline/CTA, compact fixed nav, stacked sections and horizontally scrollable card groups.
- **Breakpoint:** original responsive classes switch around Tailwind `sm`/`lg` breakpoints; the captured CSS remains authoritative.
